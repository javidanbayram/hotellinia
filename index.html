Tam İnteqrasiyalı Həll

Hotellinia sadəcə PMS deyil — rezervasiyadan gün sonuna, kassadan nüfuz idarəetməsinə qədər 35-dən çox modul vahid platformada.

Populyar

Ön Büro (PMS)

Rezervasiya, check-in/out, otaq panosu və qonaq profilləri.

  • ✓ Otaq Panosu (Room Rack) və mərtəbə planı
  • ✓ Girişlər və Çıxışlar (Check-in / Check-out)
  • ✓ Fərdi və Qrup Rezervasiyaları
  • ✓ Qonaq profilləri və tarixçə
  • ✓ Polis / rəsmi qurum bildirişi

Maliyyə və Faktura

Folio idarəetməsi, kassa, ödənişlər və mühasibat inteqrasiyası.

  • ✓ Folio və Şirkət / Agentlik hesabları
  • ✓ e-Faktura, e-Qaimə və e-Arxiv
  • ✓ Kassa və növbə əməliyyatları
  • ✓ Ödəniş və depozit idarəetməsi
  • ✓ Avtomatlaşdırılmış Gün Sonu (Night Audit)

Channel Manager və Satış

OTA inteqrasiyaları, dinamik qiymət və mövcudluq sinxronizasiyası.

  • ✓ Booking.com, Expedia, Airbnb (30+ kanal)
  • ✓ Real vaxtda qiymət və mövcudluq yenilənməsi
  • ✓ Dinamik qiymət və gəlir idarəetməsi
  • ✓ Overbooking riskinin tam aradan qaldırılması

Otaq Xidmətləri və Texniki

Otaq təmizliyinin izlənməsi, heyət tapşırıqları və təmir tələbləri.

  • ✓ Mərtəbə və otaq təmizliyi statusu
  • ✓ Avtomatik tapşırıq yaradılması və təyinatı
  • ✓ Texniki xidmət və təmir tələbləri
  • ✓ İtirilmiş və tapılmış əşyalar (Lost & Found)
  • ✓ Heyət üçün mobil tətbiq dəstəyi

POS, Restoran və SPA

Restoran, bar, otaq xidməti və SPA sifarişlərinin idarə edilməsi.

  • ✓ Planşet və toxunuşlu POS terminalı
  • ✓ Folioya (otaq hesabına) birbaşa yazılma
  • ✓ Anbar qalığı və resepturalı menyu
  • ✓ SPA və Concierge xidmətləri
  • ✓ Növbə və kassa hesabatları

Hesabatlar və Analitika

Canlı KPI izlənməsi, gəlir analizləri və dəqiq proqnozlaşdırma.

  • ✓ Doluluq (Occupancy), ADR və RevPAR
  • ✓ 18+ hazır hesabat (Kassa, Maliyyə, Agentlik)
  • ✓ Departamentlər üzrə gəlir və xərc proqnozu
  • ✓ CSV, Excel və PDF formatında ani ixrac

Qonaq Təcrübəsi və Sədaqət

Onlayn qeydiyyat, qonaq portalları və təkrar gəlişlərin artırılması.

  • ✓ Kontaktsız onlayn check-in sistemi
  • ✓ Sədaqət (Loyalty) və bonus proqramları
  • ✓ Nüfuz idarəetməsi və qonaq rəyləri
  • ✓ Qonaqlar üçün mobil tətbiq dəstəyi

Personal və Uyğunluq

Heyət nəzarəti, giriş icazələri və beynəlxalq məlumat təhlükəsizliyi.

  • ✓ Personal idarəetməsi və növbə cədvəli
  • ✓ Üz tanıma (Face ID) ilə davamiyyət izləmə
  • ✓ Qonaq və heyət üçün avtomatik bildirişlər
  • ✓ Məlumat təhlükəsizliyi və məxfilik (KVKK / GDPR)
